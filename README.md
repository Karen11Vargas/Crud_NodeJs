## Construido con 🛠️

_Herramientas Utilizadas_

- [Node js](https://nodejs.org/es/) - Entorno js
- [Express](https://nodejs.org/es/) - Framework
- [MySql](https://www.mysql.com/) - Gestor de BD
- [ejs](https://ejs.co/) - Plantillas para trabajar Html.
- [SweetAlert](https://sweetalert2.github.io/#download) - Alertas.
- Html/Css/Boostrap - Lenguajes para el FrontEnd

## Pasos para el uso

**1. Clonar repositorio**

**2. Asegurarse de tener instalado localmente el entorno node js con sus dependencias y mysql**

**3. Ejecute el query del archivo sql**

**4. Cree el archivo .env en la raiz del proyecto con la info de la bd**

```bash
#DATABASE CONFIG
DB_NAME =
DB_PASSWORD=
DB_USER =
DB_HOST =
DB_PORT =

#WEB CONFIG
WEB_HOST =
SERVER_HOST = http://localhost
SERVER_PORT = 3000

```

**5. Ejecute**

```bash
npm start
```
